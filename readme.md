【Ｒｅｔｗｉｎｓｔａ　－　ＸからＩｎｓｔａｇｒａｍへリポスト　：　Ａｎｄｒｏｉｄライフハックアプリ】<br>
<br>
Ｘ（Ｔｗｉｔｔｅｒ）からインスタグラムへリツイートができます。<br>
厳密には「リツイートする様な感覚で転載ができる支援ツール」です。<br>
公式アプリにてつぶやきの右下にある共有メニューから「その他の方法で共有」→「このアプリを選ぶ」と進んで下さい。<br>
スクリーンショットを撮って（トリミングして）Ｉｎｓｔａｇｒａｍアプリへ転送してくれます。<br>
もしくは「動画で転送する」を選べば当該ポストに貼り付けられた動画をダウンロードしてインスタグラムアプリへ転送してくれます。<br>
直接本アプリを起動しても使えます。<br>
<br>
詳しい使い方はこちら→ https://yasoo7964.web.fc2.com/android/retwin.html<br>
